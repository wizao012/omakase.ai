# omakase.ai LP

AIチャットによるWeb接客サービス「omakase.ai」のランディングページ。

## ファイル構成

```
omakase-lp/
├── index.html       メインHTMLファイル
├── css/
│   └── style.css    スタイル
├── js/
│   └── script.js    スクリプト（スムーススクロール等）
├── images/          画像素材（ロゴ・アイコン・写真）
└── .nojekyll        GitHub Pages用設定ファイル
```

## ローカルでの確認方法

`index.html` をブラウザにドラッグ＆ドロップで開けます。

## GitHub Pagesでの公開

このフォルダをGitHubリポジトリにアップロード後、
Settings > Pages からブランチを選択して公開できます。
